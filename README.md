# Simulador D2D MEO

Aplicação Android nativa para treinar VPP na venda porta a porta de MEO e MEO Energia.

## Gerar o APK

1. Abre **Actions** no GitHub.
2. Escolhe **Gerar APK Android**.
3. No fim da execução, descarrega o artefacto `simulador-d2d-meo-apk`.

O APK também é gerado automaticamente sempre que existe uma alteração no ramo `main`.
